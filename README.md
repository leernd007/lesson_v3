# Практичне завдання: Створення буклету в Canva

### 1. Відкриття сервісу
1. Перейдіть на сайт https://www.canva.com  
2. Увійдіть у свій обліковий запис або зареєструйтесь.

### 2. Створення нового дизайну
1. У полі пошуку введіть **"Буклет"** або **"Brochure"**.  
2. Оберіть один із запропонованих шаблонів.  
3. Відкрийте його для редагування.

### 3. Редагування буклету
1. Замініть текст у шаблоні на власний.  
2. Додайте:
   - заголовок
   - короткий опис теми
   - зображення
   - додаткову інформацію
3. За потреби змініть:
   - кольори
   - шрифти
   - розташування елементів.

### 4. Завершення роботи
1. Перевірте правильність тексту та оформлення.  
2. Натисніть **Поділитися → Завантажити**.  
3. Збережіть буклет у форматі **PDF** або **PNG**.

---

## Вимоги до буклету
- Буклет повинен містити **не менше 3 сторінок**.  
- Має бути **заголовок та підзаголовки**.  
- Використати **мінімум 2 зображення**.  
- Текст має бути **інформативним та зрозумілим**.  
- Дизайн має бути **охайним та читабельним**.

---

## Тема буклету (на вибір)
- Безпечний Інтернет  
- Соціальні мережі  
- Штучний інтелект  
- Кібербезпека  
- Моє місто / школа

---

## Результат роботи
Учень повинен надати:
- файл буклету (PDF або PNG)
- або посилання на дизайн у Canva.
