# Завдання 1: Обчислення вартості з фіксованою ціною

## Умова:
Створи таблицю:

| Товар      | Кількість | Сума |
|-----------|----------|------|
| Яблука    | 5        |      |
| Банани    | 3        |      |
| Апельсини | 4        |      |

## Додатково:
У клітинці **C1** запиши фіксовану ціну:
**C1 = 20**

## Формула:
У колонці "Сума":
=B2*$C$1

# Завдання 2: Розрахунок зарплати з податком

## Умова:

| Працівник | Зарплата | До виплати |
|----------|---------|------------|
| Іван     | 10000   |            |
| Марія    | 12000   |            |
| Петро    | 9000    |            |

## Додатково:
У клітинці **C1** запиши податок:
**C1 = 18%**

## Формула:
=B2-(B2*$C$1)

# Завдання 3: Конвертація валюти (USD → UAH)

## Умова:

| Товар      | Ціна (USD) | Ціна (UAH) |
|-----------|------------|------------|
| Ноутбук   | 500        |            |
| Телефон   | 300        |            |
| Навушники | 50         |            |

## Додатково:
У клітинці **C1** запиши курс:
**C1 = 40**

## Формула:
=B2*$C$1


---

# Пояснення:
- Абсолютне посилання використовується як $C$1
- Воно вказує на одну фіксовану клітинку
- При копіюванні формули адреса не змінюється
