# Завдання 1: Обчислення вартості з фіксованою ціною

## Умова:
Створи таблицю:

| Товар       | Кількість | Ціна за 1 | Сума |
|------------|----------|-----------|------|
| Яблука     | 5        | 20        |      |
| Банани     | 3        | 20        |      |
| Апельсини  | 4        | 20        |      |

## Що зробити:
- В окремій клітинці (наприклад, C2) записати ціну = 20
- У колонці "Сума" обчислити: Кількість × Ціна

## Вимога:
Використати абсолютне посилання на ціну

Формула:
=B2*$C$2

# Завдання 2: Розрахунок зарплати з податком

## Умова:

| Працівник | Зарплата | Податок (%) | До виплати |
|----------|---------|-------------|------------|
| Іван     | 10000   | 18%         |            |
| Марія    | 12000   | 18%         |            |
| Петро    | 9000    | 18%         |            |

## Що зробити:
- В окремій клітинці (наприклад, C2) записати податок = 18%
- Обчислити "До виплати":
  Зарплата - (Зарплата × Податок)

## Вимога:
Використати абсолютне посилання на податок

Формула:
=B2-(B2*$C$2)

# Завдання 3: Конвертація валюти (USD → UAH)

## Умова:

| Товар       | Ціна (USD) | Курс | Ціна (UAH) |
|------------|-----------|------|------------|
| Ноутбук    | 500       | 40   |            |
| Телефон    | 300       | 40   |            |
| Навушники  | 50        | 40   |            |

## Що зробити:
- В окремій клітинці (наприклад, C2) записати курс = 40
- Обчислити ціну в гривнях

## Вимога:
Використати абсолютне посилання на курс

Формула:
=B2*$C$2


---

# Пояснення:
- $C$2 — абсолютне посилання
- Воно не змінюється при копіюванні формули
- Без $ Excel змінює адресу (C2 → C3 → C4)
