### Завдання

1. Виділи всі оцінки:
   - вище 90 — темно-зеленим кольором
   - від 75 до 90 — світло-зеленим
   - від 60 до 74 — жовтим
   - нижче 60 — червоним

Гловна - Умовне форматування - Створити правило - Форматувати лише клітинки які містять - Задаєм умови - кнопка Форматувати - Заливка - задаєм колір - ОК

2. Додай стовпець "Статус":
   - ≥ 75 → Відмінно
   - 60–74 → Добре
   - < 60 → Потрібно покращити

3. Для стовпця "Статус" застосуй умовне форматування:
   - Відмінно — зелений текст
   - Добре — помаранчевий текст
   - Потрібно покращити — червоний текст

## Як застосувати умовне форматування до стовпця "Статус"

### Крок 1. Виділення діапазону
Виділи стовпець зі статусами (наприклад):
D2:D21

---

### Крок 2. Правило для "Відмінно"

1. Головна → Умовне форматування → Створити правило  
2. Обери: "Форматувати лише клітинки, які містять"  
3. Умова:
   - Значення клітинки → дорівнює → Відмінно  
4. Натисни "Формат" → вкладка "Шрифт" → обери зелений колір  
5. Натисни ОК  

---

### Крок 3. Правило для "Добре"

1. Створи нове правило  
2. Умова:
   - Значення клітинки → дорівнює → Добре  
3. Формат → колір тексту помаранчевий  
4. ОК  

---

### Крок 4. Правило для "Потрібно покращити"

1. Створи ще одне правило  
2. Умова:
   - Значення клітинки → дорівнює → Потрібно покращити  
3. Формат → колір тексту червоний  
4. ОК
