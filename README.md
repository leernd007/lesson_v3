### Завдання

1. Виділи всі оцінки:
   - вище 90 — темно-зеленим кольором
   - від 75 до 90 — світло-зеленим
   - від 60 до 74 — жовтим
   - нижче 60 — червоним

2. Виділи найвищу оцінку в кожному предметі (використай формулу).

3. Виділи всі оцінки нижче середнього значення по таблиці.

4. Виділи рядки повністю, якщо:
   - оцінка < 60
   - або оцінка = максимальній у своєму предметі

5. Додай стовпець "Статус":
   - ≥ 75 → Відмінно
   - 60–74 → Добре
   - < 60 → Потрібно покращити

6. Для стовпця "Статус" застосуй умовне форматування:
   - Відмінно — зелений текст
   - Добре — помаранчевий текст
   - Потрібно покращити — червоний текст

---

### Додаткове завдання (підвищеної складності)

7. Створи правило з формулою:
   - виділяй клітинки, де оцінка парне число і більше 80

8. Використай набір значків (Icons Set):
   - < 60
   - 60–80
   - > 80

9. Побудуй правило, яке підсвічує дублікати імен.

### Підказки

Формула для середнього значення:
=AVERAGE(C2:C21)

Формула для максимуму в групі:
=C2=MAXIFS(C:C, B:B, B2)

Формула для парного числа:
=AND(MOD(C2,2)=0, C2>80)
